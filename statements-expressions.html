Statements & Expressions

A statement is an instruction the program performs. An expression is a piece of code that produces a value. Statements are built out of expressions.

Statements

A statement is a complete action, and in Java it ends with a semicolon ;. Think of the semicolon as the period at the end of a sentence.

Do not forget the semicolon: a missing ; is the most common beginner syntax error.

Expressions

An expression evaluates to a value. It can be as simple as a literal or a variable, or as complex as a formula.

Numerical Expressions

Numerical expressions combine numbers, variables, and arithmetic operators. The order of operations matters - multiplication and division happen before addition and subtraction, and parentheses win over everything.

Logical Expressions

Logical expressions produce a boolean using the logical operators && (AND), || (OR), and ! (NOT).

In plain words, the three logical operators mean:

  • && (AND) is true if both conditions are true.
  • || (OR) is true if either of the conditions is true.
  • ! (NOT) is true if the condition is false.
Short-circuit: && stops as soon as the left side is false, and || stops as soon as the left side is true.

Operator Precedence

When several operators appear together, this order decides what happens first (highest first):

1 (highest)( ) parentheses
2! ++ -- unary
3* / %

Best practice: when in doubt, add parentheses. They cost nothing and make your intent clear to the reader.
