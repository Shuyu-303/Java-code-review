Arithmetic Operators

Operators are the symbols that combine values. Arithmetic operators produce numbers - and their behavior depends heavily on the types involved.

Basic Operators

OperatorMeaningExample (a=10, b=3)
+additiona + b -> 13
-subtractiona - b -> 7
*multiplicationa * b -> 30
/divisiona / b -> 3 (see below)
%modulus (remainder)a % b -> 1

Integer vs Float Division

The / symbol behaves differently depending on the operand types. If both operands are integers, the result is an integer and any remainder is thrown away.

Classic bug: 7 / 2 is 3, not 3.5. To get a decimal result, make at least one operand a double.

Modulus %

Modulus returns the remainder of a division. It is extremely useful for checking whether a number is even or odd.

Compound Assignment

These operators update a variable in one short step. x += 5 means "add 5 to x and store the result back in x".

Increment and Decrement

++ adds 1 and -- subtracts 1. The position matters: written after the variable (postfix) the old value is used first; written before (prefix) the value changes first.

Casting

Casting converts a value from one type to another. Widening (small -> large, like int -> double) happens automatically. Narrowing (large -> small, like double -> int) needs an explicit cast and truncates - it does not round.

Remember: casting a decimal to an int always moves toward zero (7.9 -> 7, -7.9 -> -7). Use Math.round() if you want rounding instead.
