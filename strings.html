Strings

A String is a sequence of characters - text. It is one of the most-used types in Java, and it comes with a large toolbox of helpful methods.

What Is a String?

A String holds text such as a name, a message, or a whole sentence. Two things to remember:

  • It is a reference type (a class), not one of the eight primitives.
  • It is immutable - String methods return a new string; they never change the original.

Creating Strings

Important: never compare strings with == - it checks whether they are the same object. Use equals() to compare their contents.

String Methods Overview

MethodWhat it does
charAt(i)Character at index i.
indexOf(s)First index of s (-1 if absent).
lastIndexOf(s)Last index of s.
length()Number of characters.
substring(a, b)Text from index a up to (not including) b.
contains(s)Whether s appears.
startsWith(s) / endsWith(s)Whether it begins / ends with s.
equals(s) / equalsIgnoreCase(s)Content equality (case-sensitive / insensitive).
compareTo(s)Alphabetical comparison (0 if identical).
replace(a, b)Replace all occurrences of a with b.
replaceAll(regex, b)Replace everything matching a regex.
replaceFirst(a, b)Replace only the first occurrence.
