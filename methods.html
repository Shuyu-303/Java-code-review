Methods

A method is a named block of code that performs one task. Name the task once, then call it as often as you like.

Purpose of Methods

Breaking a program into methods pays off in many ways:

  • Reuse - carry out repetitive tasks without copy-pasting.
  • Structure - give the program a clear, logical shape.
  • Debuggability - fix a bug in one place instead of many.
  • Teamwork - divide work among people, one method at a time.
  • Readability - a good method name explains what the code does.
Naming: methods start with a lowercase letter, have no spaces, and use a verb that describes the action - calculateTotal(), printReport(), isValid().

Structure and Syntax

The general shape of a method is:

PartMeaning
publicAccess modifier - who may call it.
staticBelongs to the class itself (callable without an object).
returnTypeWhat the method gives back - or void for nothing.
methodNameA verb describing the task, starting lowercase.
(parameterList)Inputs the method needs, with their types.

Parameters

Parameters are the inputs declared in the parentheses. When you call the method, the values you pass (the arguments) are copied into those parameters.

Return Types

If a method produces a value, its return type names that value's type and the body must return it. If it produces nothing, use void.

Calling Methods

To run a method, write its name and pass any arguments. If it returns a value, you can store or use that value.
