Variables

A variable is a named box in memory that holds a value. Java requires you to state the box's type before you use it.

Declaring Variables

Declaring tells Java to create a variable and what type it is. The pattern is type name;.

At this point the variables exist but hold no assigned value yet (you may not read them).

Initializing Variables

Initializing means giving a variable its first value with =. You can declare and initialize in one line.

Tip: declare a variable as close as possible to where you first use it, and give it an initial value immediately when you can.

Naming Conventions

Java has rules (must follow) and conventions (should follow).

Rule / ConventionGoodBad
Start with a letter, $, or _ - never a digitscore11score
No spaces or special symbolstotalPricetotal price
Use camelCase for variablesfirstNameFirstName
Avoid _ in the middle of namesmaxValuemax_value
Names are case-sensitiveage != Age-
Cannot be a reserved keywordvalueclass
Keyword clash: words like class, int, and for are reserved and cannot be used as variable names.
