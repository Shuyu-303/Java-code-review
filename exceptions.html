Exceptions

An exception is a runtime problem that interrupts the normal flow of a program. Instead of crashing, you can catch it and respond gracefully.

What Is an Exception?

An exception is an object that Java creates when something goes wrong at runtime - for example dividing by zero or opening a missing file. If you do not handle it, the program stops and prints a stack trace.

Exception vs error: an exception is a recoverable problem you can plan for; an error (like OutOfMemoryError) usually is not.

try-catch Structure

Wrap risky code in a try block and provide a catch block for the type of exception you expect.

Example

Multiple catch Blocks

You can handle different exception types separately. Order matters - put more specific exceptions before more general ones.

The finally Block

A finally block runs no matter what - whether or not an exception occurred. Use it to release resources.

Common Exceptions

ExceptionCommon cause
ArithmeticExceptionDividing an integer by zero.
NullPointerExceptionUsing a variable that is null.
ArrayIndexOutOfBoundsExceptionUsing an index outside the array.
InputMismatchExceptionReading the wrong type with Scanner.
NumberFormatExceptionConverting non-numeric text to a number.
Tip: handle exceptions you can actually recover from. Avoid empty catch blocks - silently swallowing a problem makes bugs much harder to find.
