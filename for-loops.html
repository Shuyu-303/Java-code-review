For Loops

A for loop is the go-to loop when you know how many times the body should repeat. It packs the start, the stop test, and the update into one line.

Start, Stop, Keep Going

Every for loop answers three questions:

  • Start - where does the counter begin?
  • Stop - what condition keeps the loop running?
  • Keep going - how does the counter change each pass?
Use a for loop when the number of repetitions is known in advance (for example, "do this 10 times").

Syntax (init; condition; update)

Example

Print the numbers 1 through 5, then sum them.

Loop That Never Runs

Because the condition is checked before the first pass, a for loop can run zero times if the condition is false from the start.

Infinite Loop

If the condition never becomes false, the loop runs forever. This can happen by mistake, or on purpose when you exit with break.

Watch out: a wrong update (like i-- when you meant i++) is a common cause of accidental infinite loops.

Nested for Loops

A loop inside a loop. The inner loop runs completely for each single pass of the outer loop - perfect for grids and tables.

Trace it: for row = 1 the inner loop runs col = 1, 2, 3, then the outer loop advances to row = 2, and so on.
