While Loop

A loop repeats a block of code. A while loop repeats it as long as a condition stays true.

What Is a Loop?

Without loops, repeating anything means copying and pasting code. A loop lets you write the repetition once. A while loop checks its condition before every pass through the body.

Three parts of every loop: (1) a starting value, (2) a condition to test, and (3) something inside the body that eventually changes the condition.

Flowchart of a Loop

The condition is checked first. If it is true, the body runs and control returns to the condition. If it is false, the loop ends.

Syntax and Example

Syntax: while (condition) { ... }. Make sure something inside the body moves the condition toward false.

Infinite loop: if the condition never becomes false - for example, if you forget count++ - the loop runs forever.

When to Use a while Loop

Use a while loop when either of these is true:

  • You want to stop looping when (or until) a certain condition is met.
  • You do not know ahead of time how many iterations will run.

For example, keep asking for a password until the user types the correct one - you have no idea how many tries that will take.

Using break

break exits the loop immediately, skipping the rest of the body and the condition check. It is useful when the loop's exit depends on something you discover inside the body.

Tip: use break sparingly. A well-written loop condition is usually clearer than an unexpected early exit.
