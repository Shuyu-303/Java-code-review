Data Types

Every value in Java has a type. There are eight primitive types - each fixes how much memory a value uses and what it can store.

Primitive Types Overview

Java has exactly eight primitive data types. Four hold whole numbers, two hold decimals, one holds a true/false value, and one holds a single character.

Note: String is not a primitive - it is a reference type (a class). It is covered in the Strings topic.

Integer Types

The four integer types differ only in the range of values they can hold. Prefer int unless you need a bigger range (long) or a smaller footprint.

Overflow: if a value is too big for its type, it "wraps around". Here int overflows because the result exceeds ~2.1 billion: int x = 2_000_000_000 + 2_000_000_000; // negative!

Floating-Point Types

float and double store decimal numbers. double is the default and is more precise, so use it unless memory is tight.

Precision: floating-point math is approximate. 0.1 + 0.2 prints 0.30000000000000004, not 0.3.

boolean

A boolean holds only two values: true or false. It usually stores the result of a comparison.

char and ASCII

A char stores a single character wrapped in single quotes. Internally each character is a number (its Unicode/ASCII code), so a char can be used in arithmetic.

A few useful ASCII codes:
