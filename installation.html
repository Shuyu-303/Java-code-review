Installation

To write Java you need the JDK (Java Development Kit). Here is the whole process, from download to a verified install.

Download the JDK

Get a JDK from a well-known vendor (Oracle JDK or the open-source OpenJDK / Eclipse Temurin). Choose the installer for your operating system and pick a recent LTS version such as Java 17 or 21.

  • Windows - download the .msi or .exe installer.
  • macOS - download the .dmg (or use a package manager).
  • Linux - download the .tar.gz or use your package manager.

Installing the JDK

  1. Run the installer you downloaded.
  2. Accept the license and keep the default installation folder.
  3. Let the installer finish, then close it.
Tip: Remember the install path (for example C:\Program Files\Java\jdk-21). You will need it for the PATH step.

Setting the PATH
