What is Java?

Java is a high-level, class-based, object-oriented programming language built around one famous promise: write once, run anywhere.

What is Java?

Java is a general-purpose programming language created at Sun Microsystems in 1995. You write source code in .java files, a compiler turns it into platform-neutral bytecode, and a runtime called the JVM executes that bytecode on any computer.

Because the same bytecode runs on Windows, macOS, Linux, and more, Java is called platform independent - write once, run anywhere (WORA).

Key Features

  • Object-oriented - programs are built from classes and objects.
  • Platform independent - bytecode runs on any JVM.
  • Simple and readable - C-like syntax without manual memory management.
  • Robust and secure - strong typing and automatic garbage collection.
  • Multithreaded - can do several tasks at the same time.
  • Huge standard library - thousands of ready-to-use classes.
Tip: Java is a compiled language, but it compiles to bytecode - not to machine code - which is what makes it portable.

How Java Runs (JDK/JRE/JVM)

Three acronyms you will meet constantly:

TermNameRole
JVMJava Virtual MachineRuns the compiled bytecode.
JREJava Runtime EnvironmentJVM + libraries - enough to run programs.
JDKJava Development KitJRE + compiler & tools - needed to write programs.
Note: Only javac (compiler) produces bytecode; the java command launches the JVM to run it.
