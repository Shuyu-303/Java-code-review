Nested if / else

Sometimes one decision depends on the outcome of another. Placing an if inside another if is called nesting.

What Is Nesting?

A nested if lives inside the block of an outer if. The inner condition is evaluated only if the outer condition was true.

Read it like a sentence: "If it is the weekend, then if the weather is nice, go outside."

Syntax and Example

Indentation is essential - it shows which else belongs to which if.

Beware the dangling else: an else binds to the nearest unmatched if. Always use braces { } to avoid confusion.

Checking Input with hasNext

A very common use of a nested if is checking whether the user typed the kind of value you expect before reading it. Scanner provides hasNextX() methods that return a boolean.

MethodReturns true when the next token is...
hasNext()any token at all
hasNextInt()a valid integer
hasNextDouble()a valid decimal number
hasNextLine()another line is available

Using hasNextInt

hasNextInt() is especially handy as a loop condition: keep reading numbers until the user types something that is not an integer.

Why it is safe: because hasNextInt() is true, we know nextInt() will succeed - no InputMismatchException.
