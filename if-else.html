Selection: if / else

Selection lets a program choose between different paths. The if statement runs code only when a condition is true.

Relational Operators

A condition compares two values with a relational operator and produces a boolean.

OperatorMeaningExample
==equal toa == b
!=not equal toa != b
>greater thana > b
<less thana < b
>=greater than or equala >= b
<=less than or equala <= b
Careful: = assigns a value, while == compares two values. Mixing them up is a very common bug.

The if Statement

Syntax: if (condition) { ... }. The block runs only when the condition is true.

if / else

Add an else block to run code when the condition is false. Exactly one of the two blocks runs.

else if

Chain else if to test several conditions in order. Java checks each one from top to bottom and stops at the first true condition.

Logical Operators

Combine several conditions with && (AND), || (OR), and ! (NOT).

In plain words, the three logical operators mean:

  • && (AND) is true if both conditions are true.
  • || (OR) is true if either of the conditions is true.
  • ! (NOT) is true if the condition is false.
