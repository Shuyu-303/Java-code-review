Do/While Loop

A do/while loop is like a while loop with one key difference: it runs the body at least once, because the condition is checked after the body.

Overview

With a plain while, the condition is tested first, so the body might never run. With do/while, the body always executes once before any testing happens.

Mental model: "Do this task once. Then, if the condition is still true, do it again."

Syntax

Don't forget: a do/while statement ends with a semicolon after the closing parenthesis - unlike a plain while.

Example

Keep asking for input until the user provides a positive number. The prompt must appear at least once - which is exactly what do/while guarantees.

When to Use

Choose do/while when the task must happen at least once:

  • Displaying a menu, then repeating until the user chooses "quit".
  • Asking for input again when it is invalid.
  • Rolling dice, then re-rolling until a target value appears.
Rule of thumb: if you would write the same code once and inside a loop, use do/while.
