Keyboard Input

Programs become interactive when they can read what the user types. In Java that takes just three steps using the Scanner class.

Why Keyboard Input?

So far our programs have fixed values. Reading from the keyboard lets a user supply values at runtime - names, numbers, choices - instead of hard-coding them.

Java reads input with a Scanner, a class in the java.util package.

The 3 steps: (1) import Scanner, (2) create a Scanner object, (3) call a scan method to read a value.

Call the read method that matches the type you expect. Each of these waits for the user to type a value and press Enter.

MethodReads
nextInt()an integer

nextInt vs nextLine

This is the classic beginner trap. nextInt() reads only the number and leaves the Enter key (a leftover newline) in the input buffer. The following nextLine() then reads that empty leftover instead of the user's text.

Rule of thumb: after any numeric read (nextInt, nextDouble, ...), add one input.nextLine(); before you read a line of text.
