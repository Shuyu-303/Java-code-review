Switch

A switch statement selects one branch from many based on the value of a single variable. It is a cleaner alternative to a long ladder of else if statements.

Overview and When to Use

When you compare one value against many specific possibilities, a switch is tidier than repeated if/else. For example, branching on the 13 face values of a card would need a long chain of if/else statements - but reads naturally as a switch.

Use switch when: you are testing one variable for equality against a list of fixed values.

Syntax with ->

Modern Java uses the arrow form ->. Each case names a value and the action to take. No break is needed - only the matching case runs.

Multiple Labels

One case can match several values by listing them, separated by commas. This is perfect when several inputs should lead to the same action.

The default Statement

default runs when none of the cases match. It works like the final else in an if/else chain - a safe fallback.

Best practice: always include a default so unexpected values are handled instead of silently ignored.

Flowchart

The switch evaluates its expression once, then jumps straight to the matching case.

Limitations

LimitationWhat it means
One variable onlyYou test a single expression, not conditions across several variables.
Limited typesWorks with byte, short, char, and int (plus String and enums).
Not for rangesIt matches exact values - you cannot test "between 1 and 10" directly.
Not good for: comparisons and inequalities (use if/else). Great for: menu-type situations and fixed sets of choices.
